# 报告前的准备

公开版只包含源码与文字说明，以下操作对应原笔记本已配置版本。模型、APK、回放样本与环境不在公开仓库；新设备先按[完整操作手册](完整操作手册.md)部署，并按[安卓构建说明](../android/README.md)生成本地安装包。

当前机位：外置 USB **Web Camera** 拍人员和全景；安卓手机官方 **DroidCam** 单个后置主摄拍台面。故障内置相机已不再使用。手机与电脑通过手机热点或同一 Wi-Fi 协作，不需要单片机。

## 每次启动

1. 外置相机插在电脑 USB 上。手机开启个人热点，电脑连接该热点。
2. 双击项目根目录 **启动双摄实拍.bat**，等待模型载入。
3. 打开手机 **实验台随身小屏**。点 **启动 / 设置 DroidCam**，在官方应用中选择 **Camera 0、1× 后置主摄**，不要切前摄或多摄。
4. 等电脑接到手机画面，再返回小屏。也可点 **连接 Wi-Fi 摄像头**，需要时小屏会唤醒 DroidCam，接通后返回。DroidCam 在后台采集，小屏显示守护状态、事件和电脑返回的画面。
5. 手机架在台面侧上方并保持小屏亮屏。手机 USB 可以拔掉；外置相机 USB 保持连接。

程序记住已配对的电脑地址、配对码和 DroidCam 端口。热点重开可能改变地址；地址改变时按下面方法重新配对。官方 DroidCam 是相机采集程序，小屏通过启动入口和视频接口与它协作，并未将其专有程序打包进小屏。

## 首次安装或重新配对

- 自动方式：USB 连接手机并授权调试，电脑双击 **连接安卓手机.bat**。它将安装 APK，选择与手机热点同网段的电脑地址并配对；不建立 USB 转发。完成后可拔手机线。
- 手动方式：电脑 **比赛演示 → 安卓小屏 Wi-Fi 配对信息**，手机 **配对 / 网络设置**，输入电脑热点网段地址及配对码。手机 IP 通常留空自动识别，端口默认 **4747**；自动识别失败时填官方 DroidCam 地址。手机热点场景下应填写热点网关地址，可能与 DroidCam 显示的普通 WLAN 地址不同。
- 安装包为 `android/LabGuard-Pocket.apk`，支持 Android 8.0 及以上。小屏本身不再申请或打开相机；官方 DroidCam 需要相机及通知权限以保持后台传输。
- realme 首次会确认“小屏想要打开 DroidCam”，请允许该应用协作。DroidCam 的“Power and Screen → Ignore Battery Optimizations”已在本机开启，仅针对该应用；连接恢复时可能短暂显示官方 DroidCam 窗口，然后回到小屏。

## 比赛展示

小屏“守护”查看人员、四项防护和当前事件。“待确认”表示证据不足。“画面”页可查看两路实时画面或识别标注；右侧始终预览台面。“抓拍”在电脑生成双路截图卡片；电脑核验正确或误报后，小屏“事件”同步复核结果。“静音 60 秒”和“现场求助”保留，求助只在本机主控留记录。

小屏 **停止台面传输** 会立即使手机帧失效；全景继续运行。点 **连接 Wi-Fi 摄像头** 恢复。实际 Wi-Fi 断开时旧帧最多 2.5 秒有效，随后停止该通道判断并自动重连；小屏保持前台时会在需要时唤醒 DroidCam。恢复期间可能短暂切到 DroidCam；若系统拦截切回，可按返回键回到小屏。手机锁屏后需先解锁。

电脑 **启动比赛版.bat** 默认回放两幅自带真实样本，方便熟悉界面；“比赛演示”菜单可切换实拍。演示样本不能作为独立准确率评估。默认桌边线 `labguard/config.yaml → desk.edge_line` 需要按手机机位标定。

## 帧率、来源与故障检查

- 手机只开一个后置主摄。电脑通过官方 `/video/640x480` 拉取 MJPEG，按时间节奏接收目标 **24 FPS**，丢旧保新，不积压延迟。
- 界面 Wi-Fi 实收统计唯一新帧；YOLO 的 CPU 识别帧率单独显示，通常低于视频帧率。实时画面与识别标注可分开查看。
- 全景按 DirectShow 精确名称 **Web Camera** 选择，仅接受真实帧回调；不会自动用手机或虚拟相机补位。更换外置相机时修改 `config.yaml` 的 `camera.pano_name`。
- 手机未连接：先确认热点、电脑地址、配对码和 DroidCam 4747 端口；打开 DroidCam 等电脑接到画面后再返回小屏。电脑需允许本项目 Python 的局域网入站访问，不应关闭防火墙。
- 外置全景未连接：检查插口、相机是否被其他程序独占，以及设备名。不要再切到已故障的 Integrated Camera。

## 维护与复测

电脑关闭主控窗口即可停止识别。独立 Python、依赖与本地模型位于 `labguard`，复制项目请保留 `.runtime`。运行日志、截图和事件库在 `labguard/runtime`，包含配对信息的运行目录请勿公开提交。

```powershell
# 在 labguard 目录：后端、接口、MJPEG 和重连回归
.\.runtime\python\python.exe -m unittest discover -s tests -v
# 原生界面真实模型、抓拍卡片、复核与导出
.\.runtime\python\python.exe tests\gui_smoke.py
```

根目录 `verify_phone_live.py` 是不依赖 ADB 的真实 Wi-Fi 双摄验收，结果写入 `labguard/runtime/droidcam-wifi-verification.json`。它会短暂停止并恢复台面，以检查断线失效；电脑全景保持工作。安卓可运行 `python android/build_apk.py` 使用本机 SDK/JDK 离线重建，签名保存在本机忽略目录。
